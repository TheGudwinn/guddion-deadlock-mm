# Guddion — менеджер модов для Deadlock

Настольное приложение (Tauri 2, Rust и React) для установки и управления модами Deadlock из каталога GameBanana.
Рассчитано на работу в России: прокси, зеркала, докачка файлов и локальный офлайн-кэш каталога.

*English: a desktop mod manager for Deadlock (GameBanana catalog), built to work behind blocks and on flaky networks.*

## Возможности

- **Каталог GameBanana** с поиском, категориями и сортировкой. Каталог кэшируется в локальной базе и открывается без связи.
- **Установка** из `.zip`, `.7z`, `.rar` и `.vpk` в `game/citadel/addons` с проверкой архива (защита от zip-slip, запрет исполняемых файлов, лимиты размера). Файл `gameinfo.gi` правится минимально, с резервной копией.
- **Очередь загрузок**: по одной за раз, пауза, продолжение с того же места, переживает перезапуск.
- **Библиотека**: включение и выключение, удаление, порядок загрузки (слоты `pakNN`), отмена последнего действия.
- **Профили** наборов модов с экспортом и импортом в JSON.
- **Обновления модов** и предупреждение, что игра обновилась после установки.
- **Сеть**: HTTP, HTTPS и SOCKS5 прокси, список зеркал, диагностика по шагам (DNS, TCP, TLS).
- **Автообновление приложения** с проверкой подписи; источник обновлений настраивается (GitHub Releases или зеркало).
- Без телеметрии. Моды не выполняют код: из архивов берутся только ресурсы.

## Разработка

Нужны Node 24, pnpm, Rust (stable) и на Windows Visual Studio Build Tools с компонентом C++.

```bash
pnpm install
pnpm tauri dev       # приложение с горячей перезагрузкой
pnpm build           # проверка типов и сборка интерфейса
cargo test --manifest-path src-tauri/Cargo.toml
```

Тесты используют локальные подставные серверы и встроенный PostgreSQL. Тесты с пометкой `#[ignore]` ходят в настоящий
GameBanana и запускаются отдельно: `cargo test --test live_mods_flow -- --ignored --nocapture`.

В режиме `pnpm dev` без Tauri (в обычном браузере) интерфейс показывает тестовые данные, это удобно для вёрстки.

## Выпуск

См. [RELEASING.md](RELEASING.md). Установщик для Windows (NSIS) включает WebView2 и работает без интернета.

## Что пока не проверено в самой игре

- Загружаются ли файлы с нашим префиксом `ddmm` и какой слот побеждает при пересечении файлов (предполагается, что меньший номер). В интерфейсе библиотеки это тоже оговорено.
